Three commands

The core of Velox. Real output, no mockups.

velox doctor

One command scans everything, and AI gives a full diagnosis.

$ velox doctor
- CPU: Intel Core Ultra 7 356H (16 cores), 14%
- RAM: 10240MB / 32143MB
- Drivers: 문제 장치 없음 (총 357개 정상)
[AI diagnosis] 전반 양호. 지속 부하 시 발열 관리 권장…

velox diagnose

A 3-stage AI proposes an action inside hard safety rails — whitelisted, reversible, checkpointed.

$ velox diagnose --simulate-hot
1·Customer(Claude): 과열 우려…
2·Engineer(GPT):   action=set_power_plan (balanced)
3·Confirmer(Gemini): APPROVE
조치: 전원 모드 → Balanced  (whitelist ✓ · reversible ✓)

velox snapshot / compare

Snapshot before and after a change; compare shows only what structurally moved.

$ velox compare before.json after.json
[변경] GPU · NVIDIA RTX 5070 : 32.0.15.9174 → 32.0.16.0000
